# Template Examples with Custom Fields

## 🎯 Ready-to-Use Templates

### 1. **E-Commerce: VIP Customer Discount**

**CSV Fields Needed:**
```csv
name,phone,email,company,discount,product_interest,vip_status,city
```

**Template:**
```
🎉 Hi {name}!

Thank you for being our {vip_status} member from {city}!

✨ EXCLUSIVE OFFER ✨
🎁 Special discount: {discount}% OFF
📦 On your favorite: {product_interest}

Use code: VIP{discount}

Shop now: bit.ly/shop-{company}

Valid for 48 hours only! ⏰
```
